# Training

This folder contains all scripts required to fine-tune the Container Intelligence Advisor model using QLoRA.

## Files

- config.py - Training configuration
- train.py - Fine-tuning script
- inference.py - Run inference after training
- requirements.txt - Python dependencies

## Base Model

Llama 3.2 3B Instruct

## Fine-Tuning Method

QLoRA using Unsloth

## Dataset

dataset/output/train.jsonl

## Output

models/container-intelligence-advisor/
